# 印记 · UI 改版设计方向（豆包生图用）

> 秋殇看了真机截图后的反馈：「ui 好丑，用前端 skill 改改，做得可爱，清新一点」。
> 风格方向经确认选 **「奶油薄荷 · 小芽生长」**：奶白底 + 薄荷绿，圆润软糖卡片，
> 习惯旁有手绘小芽，进度像浇水长大；与现有青绿主色连贯，功能一律不动。
> 流程：先用豆包网页版出概念图 → 确认观感 → 再把这套视觉语言落到 Android Compose UI。

## 设计令牌（改代码时按这个来）

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面底色 | `#FBF8F1` | 奶白米色，替代原来的冷灰 `#F5F8F7` |
| 卡片面 | `#FFFFFF` | 纯白 + 极柔和浅色投影 + 1px 奶油描边 |
| 主色 / 薄荷绿 | `#79C9B4` | 替代原 `#2E9C8E`，更轻更奶 |
| 主色深 | `#3E8F79` | 文字、深一档的强调 |
| 主色浅底 | `#E6F5EF` | chip / 选中态底色 |
| 点缀 奶油黄 | `#F7D98C` | 小徽章、进度高光，少量 |
| 点缀 蜜桃粉 | `#F6B8AE` | 逾期、温柔提醒，少量 |
| 文字 | `#33564B` | 深墨绿，比纯黑柔和 |
| 次要文字 | `#8AA69B` | 从主色调出的灰，不用中性灰 |
| 支出 / 逾期 | `#E8736B` | 柔和珊瑚红 |
| 收入 | `#79C9B4` | 同主色 |

形状：卡片圆角 28dp、按钮/chip 全圆、图标用统一粗细的圆润线性图标（不再用 ◉ ¥ ✎ ✓ ⚙ 这类文字符号当图标）。
插画：每个界面点缀一两株手绘小芽 / 两片叶子，今日进度卡里的小芽随完成率「长大」。
质感：软糖卡片 = 白底 + 大圆角 + 极柔阴影（有 y 偏移和模糊，不是 0 偏移光晕）+ 奶油色细描边。
字体：系统字体但拉开字重与字号层级；标题不用「大数字 + 小标签」的模板，让标题自己说话。

## 四个屏幕的概念

1. **今日 · 习惯打卡**：手写感问候「早上好，秋殇」+ 日期；薄荷绿渐变「今日进度」大卡（手绘小芽 + 圆环）；今日习惯列表 = 白色圆角卡片，左侧圆形打卡按钮、手绘小图标 + 习惯名 + 「每天 · 连续 N 天」小徽章。
2. **记账**：月度「支出 / 收入 / 结余」三列小卡；手绘甜甜圈环形「分类占比」+ 彩色圆点图例；最近记录列表；右下薄荷绿圆形「＋ 记一笔」悬浮按钮。
3. **备忘**：一行浅色输入「一句话记下来，可用 #标签」；手账纸质感便签卡片，带 #标签 小胶囊、置顶图钉与日期。
4. **待办**：「今天 / 全部 / 已完成」分段；圆形勾选框；逾期一条用蜜桃粉标「已逾期」；已完成一条加删除线并带「恢复」；右下「＋ 新建」。

底部四项圆润导航栏（今日 / 记账 / 备忘 / 待办）统一线性小图标。

## 生图提示词

- 主提示词（已放进剪贴板）：见同目录 `doubao-prompt.txt` —— 一张图并排 4 屏，做整体风格锚点。
- 备用提示词（单屏，文字更清晰、细节更足，适合先只验证「今日」页）：

```
请生成一张手机 App 界面设计稿（UI mockup），单个竖版手机屏幕，App 名「印记」，习惯打卡首页。
风格：奶油薄荷、清新可爱、手绘小芽生长主题。奶白米色背景 #FBF8F1，薄荷绿主色 #79C9B4，
奶油黄 #F7D98C 与蜜桃粉 #F6B8AE 少量点缀，深墨绿文字 #33564B。
顶部手写感问候「早上好，秋殇」与「11 月 13 日 · 周五」，右上角一个圆润的设置小按钮。
下面一张薄荷绿渐变的「今日进度」大圆角卡：卡里有一株手绘小芽插画和圆形进度环，显示「今日进度 1/3」，
小芽随进度长大，卡面有柔和的高光与一点点叶子装饰。
再下面「今日习惯」标题与「＋ 新建」，三条白色软糖圆角卡片，每条：左侧一个圆形打卡按钮
（第一条已完成显示对勾与小芽，后两条为空心圆）、中间手绘小图标 + 习惯名 + 「每天 · 连续 12 天」小徽章、
右侧一个小小的箭头。底部四项圆润导航栏：今日 / 记账 / 备忘 / 待办，用统一粗细的圆润线性小图标。
整体：大圆角 28dp、极柔和浅色投影、留白充足、干净通透、扁平手绘插画风，
不要写实照片、不要玻璃拟态、不要霓虹、不要深色背景。dribbble 风格高质量 UI 设计稿，4K 高清。
界面文字仅作示意，清晰美观即可。
```

## 注意

- 图片生成模型里的中文通常会花掉，所以**图只用来定配色 / 圆角 / 插画 / 层级气质**，文字与真实布局以代码为准。
- 概念图确认后再动 Kotlin；改动集中在 `ui/theme/Theme.kt`、`ui/Components.kt`，四个 Screen 只跟着换色值与圆角，逻辑不动。
