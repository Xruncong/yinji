请生成一张手机「桌面小组件（App Widget）」UI 设计概念图，2×2 四宫格排列，四个画面都是同一个「印记」App 放在手机主屏幕上的桌面小卡片。整体是扁平矢量插画风格的 UI 设计稿，不是写实照片。

【统一视觉语言，必须严格遵守】
- 奶白底 #FBF8F1，主色薄荷绿 #3A9A80 / 深墨绿 #2A6F5B，点缀奶油黄 #F7D98C 与蜜桃粉 #F6B8AE。
- 白色软糖卡片：28dp 大圆角、极柔和的 y 偏移模糊阴影、奶油色细描边；按钮与标签是全圆胶囊。
- 手绘笑脸小芽吉祥物（两片叶子 + 圆脑袋 + 弯眼微笑 + 蜜桃色腮红 + 周围漂浮小圆点），随画面点缀出现。
- 圆润统一粗细的线性图标，中文文字清晰可读，字色深墨绿 #33564B，辅助字 #5E7C70。
- 卡片顶部有一条四色「手账胶带」细条（薄荷绿 / 奶油黄 / 蜜桃粉 / 浅薄荷）。
- 干净、可爱、清新、留白充足；不要玻璃拟态、不要渐变文字、不要硬阴影、不要 emoji 当图标、不要系统默认字体观感。
- 每格左上角用小字标注该格功能名：「① 主卡片 4×2」「② 勾选即消失」「③ 小尺寸与空状态」「④ 桌面实景」。

【左上格 ① 主卡片 4×2】
一张放在手机主屏幕上的 4×2 桌面小组件卡片：奶白软糖卡、顶部四色手账胶带，标题行「印记 · 今天」+ 日期「11 月 15 日 周日」+ 右侧笑脸小芽。上半区分节标题「今日习惯」，下面 3 条习惯，每条左侧是空心圆圈勾选框 + 彩色圆底小图标 + 习惯名（如 早读 20 分钟 / 喝水 8 杯 / 跑步），其中 1 条已完成：文字划线变淡、圆圈里打勾。下半区分节标题「待办」，2 条待办带圆圈勾选框。底部一行小字「还有 2 项 · 点空白处打开 App」。整体层级清晰，一眼看出可以直接在卡片上勾选。

【右上格 ② 勾选即消失】
同一张卡片的交互三连状态，横向并排三张小卡：第 1 张「点一下」手指点向一条习惯的圆圈；第 2 张「划线变淡」该条变半透明并划掉；第 3 张「从列表消失」该条已不见、下方条目自然上移，右侧小芽开心。三张之间用细箭头连接，标题「勾掉即消失，App 内可恢复」。体现一次性点选即完成、不弹确认、不塞撤销按钮。

【左下格 ③ 小尺寸与空状态】
两张更小的可缩放变体上下排列：上面是 2×2 紧凑卡，只显示「今日进度 1/3」薄荷进度条 + 2 条最紧要的习惯，字号更紧凑；下面是空状态卡，中央一个大笑脸小芽 + 「今天都完成啦」+ 漂浮彩色小圆点，四周留白充足，气氛轻松有成就感。

【右下格 ④ 桌面实景】
一部手机的浅奶白色主屏幕局部：顶部有天气/时钟，中间放着这张奶油薄荷桌面小组件（与①同款但缩小），下方是几枚圆角应用图标，壁纸是极淡的薄荷奶白渐变与柔和光斑。展示小组件放在真实桌面上的观感：圆角与阴影和桌面协调，不刺眼、不突兀。

四格之间留 24px 左右间距，同一奶白背景，构图整齐、层级清晰，是一张可以直接给开发照着做的高保真 UI 概念板。注意：这些是 Android 桌面小组件（App Widget），不是 App 内页面；卡片本身是独立圆角矩形浮在桌面上。
